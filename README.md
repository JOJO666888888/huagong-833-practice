# 化工原理 833 · 背诵 + 练习

东北大学 833 化工原理分章背诵手册 + 填空练习系统（单文件网页，双击即可打开）。

## 内容

- 12 章（绪论 → 膜分离）+ 分章作战表
- 概念题 112 道（名词解释），简答题 85 道
- 空池共 **854 个**：概念 499 个（原手册 442 个 + 人工核对后补挖 57 个），简答 355 个（答案中加粗的关键术语）
- 倒计时：2026-12-20 14:00（833 专业课开考时间）

## 两种模式

- **背诵**：原手册不变——挡答案、点开单个答案、只看必考、章节打勾进度、打印。
- **练习**（工具栏点「练习」，需注册/登录账号，记录按账号保存在本浏览器）：
  - 选范围（全部 12 章或单章）+ 题型（概念 / 简答 / 全部），开始练习
  - **每次练习每道题随机抽约一半的空来挖**（概念 2—5 个，简答 2—4 个），没抽到的空正常显示；每次开始都会重新随机抽，记住的是知识点而不是空的位置
  - 空里直接填答案；带希腊字母、上下标的公式可用符号盘点选插入
  - 可暂停的计时、答题卡、进度条；中途刷新不丢，首页可继续草稿
  - 交卷自动判分（忽略全角/半角、大小写、空格和标点，上下标数字按普通数字算），错空红字显示你的答案、绿字显示正确答案
  - 刷题记录（时间、用时、分数、错空）+ 错空本 + 只练错空 + 数据导出/导入（JSON）

## 本地打开

双击 `index.html` 即可。记录存在打开它的那个浏览器里，换设备前先在「数据备份」导出 JSON，到新设备导入即可。

## 部署

单文件静态页，可直接上传到 GitHub Pages / Vercel / Netlify 等静态托管。
